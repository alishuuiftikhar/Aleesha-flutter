# Creative Design Inspiration Board

A premium Flutter application for discovering and organizing design inspiration.

## Features

- **Splash Screen**: Professional entry animation.
- **Discovery Gallery**: Masonry-style grid with high-quality images.
- **Categories**: Filter by Graphic Design, Interior Design, Fashion, Photography, UI Design, and Color Palettes.
- **Advanced Search**: Find inspiration by title or author.
- **Moodboards**: Create and manage custom boards for your projects.
- **Favorites**: Save your favorite inspirations for quick access.
- **Notes**: Add thoughts and ideas to specific inspirations.
- **Color Palettes**: View extracted color palettes for every design.
- **Full-Screen Viewer**: Immersive image inspection with zoom.

## Tech Stack

- **Flutter & Dart**
- **Provider**: State management.
- **Shared Preferences**: Local data persistence.
- **Staggered Grid**: Beautiful masonry layouts.
- **Google Fonts**: Premium typography.
- **Cached Network Image**: Performance-optimized image loading.
